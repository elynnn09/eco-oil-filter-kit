# Eco Oil Filter Website

This is a static website project. It does not require a build step.

## Open and edit

- Open `index.html` in a browser to view the site.
- Edit `index.html` to change page text, layout, colours, and controls.
- Edit `assets/eco-oil-scene.js` to change the 3D model, assembly animation, water/oil movement, and interactions.
- Replace or update images in `assets/` while keeping the filenames referenced by `index.html`.

Three.js and GSAP load from public CDNs, so an internet connection is needed for the interactive 3D scene.

## Publish online

Upload the contents of this folder to any static website host. Keep `index.html` and the `assets/` folder together so the images and 3D script paths continue to work.
